Welcome / Hero Banner

Behaviour
  • Displays a time-aware greeting (Good Morning / Afternoon / Evening / Night) using the user's local clock.
  • Shows the logged-in user's full name highlighted in the greeting.
  • Displays a role badge label: Steward Dashboard (member) / Steward Administrator Panel (leader) / Sovereign System Core (admin).
  • The sub-text paragraph changes based on role — member sees their hub name, leader sees their hub's member count and pending approvals count, admin sees global control message.

Professional Stats Panel (4 Cards)

Card 1 — My Hub (Verified Vocation Peers)
  • Shows the total count of approved members in the logged-in user's hub.
  • Fetched from hub_members where hub_id matches the user's hub and status = 'approved'.
Card 2 — Connections (Network Circle Size)
  • Shows the total count of accepted connection requests for the logged-in user.
  • Fetched from connection_requests where the user is sender or receiver and status = 'accepted'.
Card 3 — Guild Status
  • Shows the user's membership status: Active Member (green) or Pending (amber) or Rejected (red).
  • Displays the user's hub name below the status.
  • Status is read from hub_members.status for the current user.
Card 4 — Conditional (Role-based)
  • Leader / Admin: Shows count of pending hub membership applications with a link navigating to the Leader Panel.
  • Member: Shows an "Inspect Church Directory" shortcut card that navigates to the Members Directory.
Leader — pending approvals Admin — pending approvals Member — directory shortcut
Required API Endpoints
GET /dashboard/stats.php

Returns: hub_member_count, connections_count, membership_status, pending_approvals_count (for leader/admin)

Recent Platform Bulletins (Announcements Feed)

Display Rules
  • Shows announcements where hub_id matches the user's hub OR where hub_id is NULL (platform-wide / global announcements).
  • Each post shows: author name, author role/title, hub tag, date posted, post title, post body content.
  • Posts are sorted by created_at descending (newest first).
  • Empty state shown when no announcements exist for the user's hub.
User Interactions
  • Like: Users can like/unlike an announcement. Like count updates in real time. State stored per user in the DB.
  • Comments: Comment count shown; clicking navigates to the Messages or a comment thread (future feature).
  • Post Bulletin (Leader only): A "+ Post Bulletin" button visible only to leaders navigates to the Leader Panel to compose a new announcement.
All Roles — read & like Leader — post bulletin Admin — post & delete

Upcoming Formations (Events Panel)

Display Rules
  • Lists upcoming events where event_date >= NOW(), sorted by nearest date first.
  • Shows events global to all hubs, or scoped to the user's specific hub.
  • Each event card shows: hub tag, event title, short description, speaker name & title (if set), date, time, location.
  • Shows current attendee count on the registration button.
User Interactions
  • Register / Unregister: Toggle button registers or unregisters the user for an event. Button text and style change to reflect current state (registered = green check).
  • Attendee count updates immediately on toggle.
  • Registration state persists in event_registrations table.
All Roles — register/unregister Leader — can create events (in Leader Panel) Admin — can create & delete events
